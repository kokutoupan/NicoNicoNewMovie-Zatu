# ニコニコのフォロー新着(動画)
ニコニコの新着動画を見るChromeの拡張機能です。<br>
ポップアップで新着動画を確認することができます。<br>

## インストール
1. Relesesからダウンロードする
2. ダウンロードしたzipファイルをChromeの拡張機能のところにドラッグアンドドロップする

## 使用方法
  ニコニコ動画でこの拡張機能を選択する

## 開発者向け

### セットアップ
このプロジェクトでは `pnpm` を使用します。`pnpm` がインストールされていない場合は、まずインストールしてください。

```bash
# 依存関係のインストール
pnpm install
```

### 開発
変更を監視し、自動的にビルドする開発サーバーを起動します。

```bash
pnpm dev
```

### ビルド
拡張機能のファイルを `dist` ディレクトリにビルドします。

```bash
pnpm build
```

### リリース用パッケージの作成
`dist` ディレクトリの内容をzipファイルにまとめ、`release` ディレクトリに配置します。

```bash
pnpm run release
```
